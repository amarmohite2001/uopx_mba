# AGENTS.md

## Purpose

This is an MBA student workspace for University of Phoenix coursework. Keep
course materials organized, easy to review, and separate from personal or
administrative documents.

## Course Organization

- Keep each course in its own root-level folder.
- Store study notes, discussion summaries, assignment drafts, and the syllabus
  inside that course folder.
- Use descriptive Markdown names such as `Week 2 Strategic Planning.md`.
- Keep university-provided templates and submitted documents intact unless a
  change is explicitly requested.

## Current Course

The first and current course is identified as `MGT/256` by the student. Its
existing materials are currently stored in `MGMT526/`; confirm the course code
before renaming or moving that folder.

## Working Rules

- Read existing course notes before adding related material.
- Preserve existing formatting and citations in assignment documents.
- Do not overwrite templates, syllabi, or completed submissions.
- Update the root `Readme.md` when adding a course folder or major study note.
